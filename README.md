# Projeto de ciência de dados para a Vigilância Epidemiológica

Repositório de recursos de ciência de dados para a vigilância epidemiológica

Este projeto visa estabelecer meios para projetos de ciência de dados na prática profissional da vigilância epidemiológica, fornecendo os conhecimentos necessários para compreender os conceitos básicos, fluxos de trabalho, ferramentas e produtos a serem gerados ao longo do processo.
